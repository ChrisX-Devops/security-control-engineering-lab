# Control Mapping — IAM Access Review

## Control Area
Access Control

## Control Objective
Ensure access to cloud resources is provisioned using least privilege and monitored for excessive permissions.

## Violated Principles
- Least Privilege
- Access Governance
- Privileged Access Management

## Framework Mapping

### SOC 2
CC6.1 – Logical access security measures are implemented to protect system resources.

### ISO 27001
A.5.15 – Access control  
A.8.2 – Privileged access rights

## Control Failure
IAM user was granted unrestricted administrative permissions without role scoping or justification.
