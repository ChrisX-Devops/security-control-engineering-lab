# Communications

This folder contains stakeholder-facing materials, sales
documents, and frameworks for translating technical security
work into business outcomes.

## Structure

communications/
├── memos/ ← Stakeholder communication examples
│ ├── memo-01-critical-finding.md ← What to send when CRITICAL detected
│ ├── memo-02-weekly-status.md ← Weekly executive update template
│ └── memo-03-founder-outreach.md ← Cold outreach to founders
│
├── sales/ ← Sales and positioning documents
│ ├── service-offerings.md ← Service packages and pricing
│ ├── 30-second-pitch.md ← Memorized pitch versions
│ ├── objection-handling.md ← Common objections + responses
│ └── personal-brand.md ← Brand statement and positioning
│
└── frameworks/ ← Decision-making frameworks
├── remediation-prioritization.md ← How to rank findings
└── translation-reference.md ← Tech to business language


## Why This Folder Exists

Technical work without communication = ignored work.

Every artifact in this folder is designed to:
- Convert findings into action
- Justify investment in security
- Position you commercially
- Win client trust quickly

## How to Use These Documents

**As templates:** Copy and customize for real engagements

**As training:** Read aloud daily until the language becomes natural

**As proof:** Show prospects you understand business, not just code

## Updates

Update these documents whenever you:
- Discover a better explanation that lands with stakeholders
- Encounter a new objection you handled well
- Learn a new framework that helps prioritization
- Win a client and find what made the difference
